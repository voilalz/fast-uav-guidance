# 高速小型固定翼无人机 GNSS 拒止条件下自主导航方案设计

> 适用对象：巡航速度约 600 km/h（≈167 m/s）、典型飞行高度约 1 km AGL 的小型固定翼无人机
> 文档状态：方案设计 v0.2（已按确认约束修订：商用级 MEMS 惯导、森林山地/城市地形、自建影像库、导航输出 30 Hz）
> 配套脚本：[`tools/error_budget.py`](../tools/error_budget.py)（文中误差数值均可由该脚本复现）

---

## 1. 问题定义

### 1.1 背景

- GNSS 被干扰/欺骗/拒止后，若只靠惯导（INS）推算，位置误差随时间超线性增长（陀螺零偏引起的误差近似按 t³ 增长）。
- 600 km/h 时每分钟飞行 10 km、每小时 600 km。同样的漂移时间，对应的航程比旋翼/低速平台长一个数量级，任务对“每公里漂移”非常敏感。
- 主流视觉/激光 SLAM 面向低速、近距离、可回环的场景，直接搬到本平台会遇到以下问题：
  1. **无回环**：航线基本不重访，SLAM 的核心优势（回环消除累积误差）用不上，退化为视觉里程计（VO），误差仍随航程累积。
  2. **前视几何退化**：1 km 高度下地面近似平面且距离远，前视相机视差小、尺度不可观、深度三角化病态。
  3. **激光雷达失效**：小型机载激光雷达有效距离通常 100–200 m，1 km 高度基本无回波。
  4. **算力与 SWaP**：小型机载平台功耗/体积/重量受限，难以承载大规模建图和全局优化。
  5. **高动态与时间同步**：167 m/s 下 10 ms 时间戳误差即 1.7 m 位置误差；图像处理延迟 200 ms 即 33 m。

### 1.2 已确认约束

| 约束 | 内容 | 对方案的影响 |
|---|---|---|
| 惯导 | 商用级 MEMS | 纯惯导 1 min 即数十米、5 min 达公里级，**必须连续速度辅助 + 高频绝对修正**，见 §4.0、§6 |
| 地形 | 森林山地、城市 | 山地：地形匹配与三维地形匹配强；城市：影像匹配强；森林：影像纹理弱且随季节变化，需多手段互补，见 §4.6 |
| 影像库 | 目前没有，可自建 | 需要建库流程与数据规范，见 §4.7 |
| 输出帧频 | ≥ 30 Hz | 由惯导高频推算保证，与修正频率解耦，见 §5.6 |

### 1.3 设计目标（建议指标，待评审确认）

| 项目 | 指标 |
|---|---|
| 水平定位精度（有可匹配地物/地形区域） | CEP ≤ 30 m，95% ≤ 50 m |
| 匹配困难区（水面、沙漠、云下）持续 5 min 后 | 水平误差 ≤ 300 m（1σ 量级） |
| 高度精度 | ≤ 10 m（相对 DEM / 海拔） |
| 导航输出频率 / 延迟 | ≥ 30 Hz（设计余量 100 Hz）/ ≤ 10 ms |
| 全天候 | 昼间可见光 + 夜间/低照度红外 |
| 完好性 | 具备匹配错误检测与告警，单次错误匹配不得使滤波发散 |

### 1.4 核心思路

**惯导负责“短时高频、连续”，绝对位置由“与先验地图匹配”周期性提供，速度/相对运动由视觉里程计和大气数据约束误差增长，全部在误差状态卡尔曼滤波（ESKF）中统一融合。**

也就是用 *地图匹配（Map-based Localization）* 替代 SLAM 中的回环，用卫星正射影像和数字高程模型（DEM）充当“事先建好的地图”。

### 2.1 分层结构

| 层次 | 功能 | 频率 | 作用 |
|---|---|---|---|
| L0 惯导解算 | 捷联姿态/速度/位置积分 | 200–1000 Hz | 高频连续输出，任何时候都可用 |
| L1 相对约束 | 视觉里程计/光流测速、空速+风估计、气压高度 | 10–50 Hz | 抑制速度误差 → 把位置误差从 t³ 压到近似线性增长 |
| L2 绝对修正 | 景象匹配（影像↔卫星正射图）、地形轮廓匹配（雷达高度表↔DEM） | 0.1–2 Hz | 消除累积误差，使零偏可观测 |
| L3 完好性 | χ² 门限、多假设、跨源一致性、模式降级 | 每次量测 | 防止错误匹配导致发散 |

## 3. 传感器选型建议

| 传感器 | 推荐规格 | 说明 |
|---|---|---|
| IMU | 商用级 MEMS（已确认）；建议 4–8 片组成 IMU 阵列 + 温控/温补 + 减振 | 阵列平均可将噪声降低约 √N 倍；决定匹配失败时“能撑多久”，见 §4.0、§6 |
| 下视可见光相机 | 全局快门，2–5 MP，像元 3.45 µm，焦距 8–16 mm，硬件触发 | 全局快门避免卷帘畸变；1 km 高度 GSD 0.2–0.4 m，幅宽 0.5–1 km |
| 下视长波红外 | 640×512，12 µm，焦距 25 mm 左右 | 夜间/低照度；GSD ≈ 0.5 m |
| 雷达高度表 | 量程 ≥ 1.5 km，精度 1–2 m 或 1% | TERCOM 与高度通道约束；对植被/水面有穿透差异需建模 |
| 大气数据 | 皮托管空速 + 攻角/侧滑 + 静压 | 速度约束（与风联合估计）、气压高度 |
| 磁罗盘 | 三轴磁强计，需机载硬软铁标定 | 航向辅助，低权重使用 |
| 导航计算机 | 嵌入式 GPU/NPU（如 Jetson Orin NX 级别）+ 实时 MCU | GPU 跑匹配网络，MCU 跑惯导与滤波 |
| 时间同步 | 统一硬件时钟，相机曝光中点打时间戳，误差 ≤ 0.1 ms | 167 m/s 下 1 ms = 0.17 m |

**成像关键约束**（H = 1 km，V = 167 m/s，详见脚本输出 §三）：

- 运动模糊 = V × 曝光时间 / GSD。f = 16 mm、像元 3.45 µm（GSD 0.22 m）时，曝光 500 µs → 0.39 px，可接受；曝光 1 ms → 0.77 px，临界。**建议曝光 ≤ 300–500 µs**，配大光圈镜头和高灵敏度传感器。
- 下视光流角速率 V/H ≈ 0.167 rad/s；10 Hz 时地面每帧位移 16.7 m（约 1/30–1/60 幅宽），帧间重叠率 > 95%，对 VO 很友好。**高速本身对下视视觉并不困难，困难在于无回环、尺度和长航程累积**，这也是本方案不以 SLAM 为主的原因。

## 4. 关键子系统

### 4.0 商用级 MEMS 的专项措施

商用级 MEMS（本文按偏保守的参数估算：陀螺零偏 10°/h、加计零偏 2 mg；常见商用/工业级产品零偏不稳定性约 1–10°/h，实际以选定型号的 Allan 方差标定为准）单独使用时几分钟即发散，本方案的定位是：**IMU 只负责高频姿态与短时（秒级）运动推算，位置精度完全依赖外部辅助**。为此：

1. **IMU 阵列**：4–8 片同型 MEMS 刚性安装、数据融合，随机噪声降低约 √N，并可做单片故障剔除。
2. **温度标定与温补**：地面多温度点标定零偏、比例因子、轴间失准，机内加恒温或温度建模补偿。商用级 MEMS 零偏的主要变化来自温度。
3. **减振**：600 km/h 平台动力/气动振动强，需机械减振并检查振动整流（vibration rectification）和 g 敏感误差。
4. **GNSS 段在线标定**：起飞后 GNSS 可用阶段完成零偏、比例因子、相机/空速参数的在线估计，拒止后以此为初值。
5. **连续速度辅助**：视觉里程计 + 空速/风，使水平姿态和横滚/俯仰陀螺零偏持续可观测，避免姿态误差通过重力耦合放大为位置误差。
6. **航向不能靠陀螺保持**：商用级 MEMS 陀螺无法寻北，航向由 景象匹配（直接给出旋转角）、连续两次位置修正的航迹方向、磁罗盘 三者约束。
7. **提高绝对修正密度**：按 §6.2 计算，相邻成功修正间隔应控制在 **5 km（约 30 s）以内**，最长不宜超过 10 km。

### 4.1 捷联惯导与高度通道

- 采用 WGS-84 下的 NED 或 ECEF 机械编排，考虑地球自转与牵连角速度（600 km/h 下牵连角速度不可忽略）。
- 高度通道本身不稳定，用气压高度 + 雷达高度表（结合 DEM：海拔 = 雷达高 + 地形高）阻尼。
- 初始对准：GNSS 失效前由 GNSS/INS 组合完成精对准，并将各零偏估计值作为拒止阶段的初值，这一点对长时间拒止至关重要。

### 4.2 视觉里程计 / 光流测速（相对约束）

- **下视单目 + 高度 = 有尺度**：以雷达高度表（或 DEM 修正后的高度）提供尺度，地面近似局部平面，用单应矩阵分解或直接法求帧间平移，输出机体速度（或两帧间位移）量测。
- 选用轻量前端：FAST/ORB 或 KLT 光流跟踪，或学习型特征（SuperPoint 轻量版）；后端不做全局 BA，只做滑窗（MSCKF 式）或直接作为速度量测进 ESKF，算力可控。
- 期望性能：速度误差 0.5%–2% V。这是把纯惯导的 t³ 漂移降为近似 **线性随航程增长** 的关键。在商用级 MEMS 条件下，VO 是主导的速度源，其尺度误差直接决定修正间隙内的漂移。
- **森林上空的尺度问题**：雷达高度表在林区可能测到树冠、地面或二者之间，造成数米至数十米的高度偏差，进而带来 1%–3% 的 VO 尺度误差。建议林区用“气压海拔 − DEM 地形高”或运动恢复结构（§4.6）得到的地表高度作为尺度来源，雷达高度表仅作交叉校验。
- 退化场景：水面、雪地、云雾、强纹理重复。用特征数量/内点率/单应残差做质量评价，质量差时降权或停用。

### 4.3 景象匹配（视觉绝对定位，主修正源）

把实时下视图像与机载存储的卫星正射影像（DOM）配准，获得绝对位置（必要时含航向）。

**处理流程：**

1. **先验预测**：用当前 ESKF 位置/姿态与协方差，确定参考图搜索区域（3σ 椭圆）并裁切参考影像。
2. **实时图正射校正**：利用姿态和高度（必要时叠加 DEM）把实时图投影到地面平面，统一尺度和朝向，消除透视差异——这一步使匹配从“跨视角”变为“同视角”，难度大幅降低。
3. **粗匹配**：多尺度 NCC/相位相关，或学习型全局描述子（如 NetVLAD/AnyLoc 类）在搜索区内检索候选位置。
4. **精匹配**：SuperPoint + LightGlue、LoFTR 等局部特征匹配 + RANSAC 单应估计，得到亚像素级偏移。
5. **质量评估**：内点数、内点分布、峰值旁瓣比（PSR）、多候选歧义度，生成量测协方差。
6. **输出**：带时间戳（曝光时刻）的绝对位置量测及协方差，送 ESKF。

**设计要点：**

- 参考图分辨率 0.5–1 m 即可，全程按航线走廊（如两侧各 5 km）预存。按 1 m 灰度、压缩后估算，影像库 + DEM 约每 1000 km 航线数 GB 到十几 GB，机载 SSD 可承载（建库细节见 §4.7）。
- 跨季节/跨时相/跨光谱（红外实时图 ↔ 可见光参考图）是主要难点：建议用跨模态训练的学习型匹配网络，并在航线规划阶段对走廊内“可匹配性”做离线评估（纹理丰富度、地物稳定性），生成 **可匹配性地图**，让航迹尽量经过高可匹配区域。
- 期望精度：2–5 倍参考图 GSD，即 5–20 m（1σ）。
- 处理时延：机载 GPU 上 100–300 ms，需按 §5.4 做延迟量测处理。

### 4.4 地形轮廓匹配（TERCOM / SITAN，补充修正源）

- 雷达高度表测得离地高，与惯导/气压海拔相减得到沿航迹地形剖面，与 DEM 做相关匹配。
- **批处理 TERCOM**：采样 5–10 km 剖面（30–60 s）做二维搜索，鲁棒、捕获范围大，适合初始捕获或长时间失配后重捕获。
- **递推 SITAN**：在 ESKF 中把地形斜率线性化做连续量测，精度高但需要先验误差较小（< 几百米）。
- 适用：起伏地形（山地、丘陵）；平原、水面无效。与景象匹配互补：植被茂密、季节变化大的山区影像难匹配，但地形起伏大，TERCOM 效果好。
- DEM：SRTM/Copernicus 30 m，垂直误差 5–10 m；期望水平精度 30–100 m，地形粗糙度越大越好。

### 4.5 大气数据与风估计

- 空速 + 攻角/侧滑 + 姿态 → 空速矢量；地速 = 空速 + 风。将二维水平风速（含一阶 Gauss-Markov 模型）加入状态。
- 有绝对修正时风可观测，修正间隙时风缓慢变化，空速量测能有效约束速度误差（相当于又一个“里程计”）。
- 需对皮托管的位置误差和标定系数建模（可加入比例因子状态）。

### 4.6 森林山地与城市的针对性策略

| 场景 | 主修正源 | 辅助 | 难点与对策 |
|---|---|---|---|
| 城市 | 景象匹配（道路网、建筑轮廓、地标纹理丰富且跨季节稳定） | VO、空速 | 1 km 高度下高楼存在投影位移：参考图用真正射影像（基于 DSM 校正），实时图用 DSM 正射校正；道路/建筑轮廓等结构化特征比纹理更稳健 |
| 山地（林木覆盖） | 地形匹配：TERCOM/SITAN + **三维地形匹配** | 山脊线/阴影景象匹配、VO | 起伏大，地形信息量丰富；DEM 误差在陡坡处放大，需用坡度加权 |
| 森林平缓区 | 三维地形匹配 + 长波红外景象匹配 | VO、空速 | 冠层纹理重复且季节变化大；林缘、道路、河流、林间空地是稳定特征；必要时缩短在此区段的航程 |

**三维地形匹配（推荐作为山地/森林的核心手段）**：下视单目相机在 1 s 内飞行约 167 m，形成足够的立体基线（B/H ≈ 0.17），可由运动恢复结构实时重建航迹下方的地表高程（精度约 0.5–1 m，见脚本输出 §五），再与参考 DSM/DEM 做三维配准（ICP 或高程相关）。相比 TERCOM 只用沿航迹一条剖面，它使用整条成像带的二维地形，信息量大一个数量级，捕获更快、精度更高；且对光照、季节变化不敏感（森林冠层表面与 DSM 一致）。

**阴影地形渲染匹配**：在山地，利用飞行时刻太阳方位角对 DEM 渲染晕渲图，再与实时图做匹配，可在植被纹理不稳定时利用山体明暗结构定位。

### 4.7 影像与地形参考库建设

参考库目前不存在，需要随项目建设。建议分两级：

**一级：卫星数据库（覆盖广，快速建立）**

| 数据 | 推荐来源 | 分辨率 | 用途 |
|---|---|---|---|
| 正射影像 DOM | 国产高分系列（如高分二号、吉林一号）或商业卫星影像 | 0.5–1 m | 景象匹配参考图 |
| 数字高程模型 DEM | Copernicus GLO-30、ALOS AW3D30 等 | 30 m | TERCOM/SITAN、正射校正 |
| 数字表面模型 DSM | 卫星立体像对生产 | 2–5 m | 城区真正射、三维地形匹配（森林冠层表面） |
| 多时相影像 | 同一区域不同季节 2–4 期 | 同上 | 应对森林季节变化 |

**二级：航测补充库（任务区，精度最高）**

在 GNSS 可用条件下，用本机或低成本航测平台携带同型下视相机沿任务走廊飞行，通过航空摄影测量生产 DOM/DSM。优点是传感器、视角、分辨率与实际飞行一致，匹配成功率最高；同时积累的真值数据可直接用于 §8 的算法验证。

**建库处理流程**：

1. 数据采集与坐标统一（WGS-84 / CGCS2000，统一高程基准）。
2. 几何精校正：利用控制点把影像地理定位误差控制在 ≤ 3 m。
3. 真正射校正（城区）、多时相配准。
4. 瓦片化与金字塔：按 1 km × 1 km 瓦片、多级分辨率存储。
5. 离线特征预提取：每个瓦片预先计算局部特征点/描述子和全局描述子，机上只需提取实时图特征，节约算力。
6. **可匹配性评估**：对每个瓦片计算纹理丰富度、地形粗糙度、季节稳定性，生成可匹配性地图，供航路规划和滤波器量测权重使用。
7. 版本与完整性校验：带时相和精度元数据，加载前做哈希校验。

存储估算：1 m 分辨率、走廊宽 10 km、航程 1000 km 约 10^10 像素，8 bit 灰度压缩后约 2–5 GB；加上 DSM、多时相和预提取特征，总量约 10–20 GB。

### 4.8 可选扩展

- **天文导航**：1 km 高度昼间难以观星，仅作为夜间/高空巡航扩展选项，可约束航向与姿态。
- **地磁匹配**：在地磁异常显著区域可作额外绝对修正源，但需高精度磁测与机体磁干扰补偿，作为研究性选项。
- **前视相机**：用于末段/目标区，不作为主导航源。

## 5. 多源融合：误差状态卡尔曼滤波（ESKF）

### 5.1 状态向量（误差状态）

| 状态 | 维数 | 说明 |
|---|---|---|
| δp 位置误差 | 3 | |
| δv 速度误差 | 3 | |
| δθ 姿态误差 | 3 | 小角度，避免四元数约束问题 |
| b_g 陀螺零偏 | 3 | 随机游走 |
| b_a 加计零偏 | 3 | 随机游走 |
| w_N, w_E 水平风 | 2 | 一阶 Gauss-Markov |
| b_baro 气压高度偏差 | 1 | 随气象变化 |
| k_as 空速比例因子 | 1 | 可选 |
| δt_cam 相机时间偏移 | 1 | 可选，在线标定 |
| 相机-IMU 安装角 | 3 | 可选，在线精化 |

基础 18 维，含可选项 23 维左右，MCU 上 100–200 Hz 预测完全可行。

### 5.2 量测模型

| 量测 | 形式 | 频率 | 典型 1σ |
|---|---|---|---|
| 景象匹配位置 | 水平位置（± 航向） | 0.5–2 Hz | 5–20 m |
| TERCOM 位置 | 水平位置 | 0.02–0.05 Hz | 30–100 m |
| 三维地形匹配位置 | 水平位置 + 高度 | 0.2–1 Hz | 10–30 m（山地） |
| SITAN | 雷达高 = 海拔 − DEM(x,y)，线性化地形梯度 | 10–50 Hz | 3–10 m（高） |
| VO 速度/位移 | 机体系速度或帧间位移 | 10–30 Hz | 0.5–2% V |
| 空速 | 空速矢量 = R(地速 − 风) | 50 Hz | 1–2 m/s |
| 气压高度 | 海拔 + b_baro | 50 Hz | 2–5 m |
| 雷达高度 | 离地高 | 50 Hz | 1–2 m |
| 磁航向 | 航向 | 10 Hz | 1–3° |

### 5.3 鲁棒性与完好性

- **新息 χ² 门限检验**：每个绝对量测先做马氏距离检验，超限拒绝，并记录连续拒绝次数。
- **多假设匹配**：景象匹配给出 Top-K 候选；若存在歧义（如重复纹理），以多假设（MHT / 粒子滤波短时并行）处理，待后续量测消解后再并入主滤波。
- **跨源一致性**：景象匹配与 TERCOM、VO 积分轨迹相互校验，两个独立源一致才接受大幅修正。
- **协方差自适应**：根据匹配质量指标（内点率、PSR）动态调整 R；可引入 Sage-Husa 或基于新息的自适应估计。
- **故障恢复**：长时间失配（> N 分钟）后扩大搜索窗口，切换到 TERCOM 批处理大范围重捕获。

### 5.4 延迟量测处理

图像匹配从曝光到出结果有 100–300 ms 延迟（16–50 m 航程）：

- 方案 A（推荐）：**状态克隆 / 随机克隆（Stochastic Cloning）**——曝光时刻克隆位置/姿态状态，量测到达后对克隆状态更新并通过互协方差传播到当前状态。
- 方案 B：保存历史 IMU 和状态缓冲，量测到达后回滚到曝光时刻更新再快速重新积分到当前时刻。

### 5.5 可观测性说明

- 只有位置量测时，水平姿态通过加速度与位置的耦合可观测；航向在直线匀速飞行时弱可观测，需机动（转弯、加减速）或磁航向/景象匹配航向量测辅助。
- 航路规划时建议在进入长时间失配区前安排一次小机动，以提升航向和零偏估计精度。

### 5.6 30 Hz 导航输出的实现

输出帧频与修正频率解耦：

- 惯导以 IMU 采样率（≥ 200 Hz，建议 400 Hz）做捷联解算和 ESKF 时间更新，任意时刻都有最新解，**按 30 Hz（或更高）定时输出**完全无压力。
- 各类修正量测（VO 10–30 Hz、景象匹配 0.5–2 Hz、地形匹配 0.02–50 Hz）按到达时间异步更新，到达后通过 §5.4 的延迟处理回到曝光时刻再前推，输出不出现跳变时可对修正量做数百毫秒的平滑过渡。
- 下视相机建议 30 Hz 硬件触发，与输出同频，VO 每帧更新；景象匹配和三维地形匹配只取其中的关键帧。
- 计算分工：MCU（实时）负责 IMU 采集、捷联解算、ESKF 和 30 Hz 输出；GPU/NPU 负责 VO 前端、景象匹配和三维重建，通过共享时间戳的消息接口交互，GPU 侧卡顿不影响导航输出连续性。

## 6. 误差预算与可行性分析

以下数值由 `python3 tools/error_budget.py` 计算（单通道 Schuler 模型，各误差源 RSS，为量级估计）。

### 6.1 纯惯导水平漂移

| IMU 等级 | 1 min | 5 min | 10 min | 30 min | 60 min |
|---|---|---|---|---|---|
| 商用级 MEMS (10°/h, 2 mg，本项目假设) | 61 m | 2.5 km | 17 km | 发散 | 发散 |
| 高端 MEMS (1°/h) | 23 m | 0.5 km | 2.6 km | 39 km | 144 km |
| 战术级 FOG (0.1°/h) | 11 m | 0.2 km | 0.9 km | 6.6 km | 17 km |
| 导航级 (0.01°/h) | 4 m | 47 m | 177 m | 1.1 km | 1.9 km |

结论：本项目使用的商用级 MEMS **纯惯导 5 分钟（50 km 航程）误差已达 2–3 km、10 分钟达十余公里**，单靠惯导没有可用性，必须以连续速度辅助和高频绝对修正为前提进行设计。

### 6.2 组合后修正间隔与搜索窗口

两次绝对修正之间由 INS + VO + 空速推算，误差近似随航程线性增长；下一次匹配的先验 3σ 搜索半径：

| 相对速度误差 | 间隔 5 km | 10 km | 20 km | 50 km |
|---|---|---|---|---|
| 0.5% | 87 m | 157 m | 303 m | 751 m |
| 1.0% | 157 m | 303 m | 602 m | 1.5 km |
| 2.0% | 303 m | 602 m | 1.2 km | 3.0 km |

结论：

- 景象匹配幅宽 0.5–1 km，只要 **相邻成功修正间隔 ≤ 10–20 km**（约 1–2 min），先验误差就落在一次成像覆盖范围内，可做局部精匹配，无需全局检索。
- 水面/沙漠等无匹配区段若超过 50 km，误差将超过 1 km，需要 TERCOM 或大窗口检索重捕获，航路规划应避免或缩短此类区段。

**商用级 MEMS + VO/空速辅助**（脚本输出 §四；初始航向残差 0.3°，上次修正残差 15 m）：

| 条件 | 间隔 2 km | 5 km | 10 km | 20 km |
|---|---|---|---|---|
| VO 速度误差 1% | 77 m | 164 m | 327 m | 687 m |
| VO 速度误差 2% | 129 m | 307 m | 614 m | 1.2 km |

在有连续速度辅助时，陀螺 z 轴零偏（10°/h 与 3°/h 结果几乎相同）不再是主要矛盾，**VO 的尺度/速度误差主导修正间隙的漂移**。因此森林区的尺度来源（§4.2）尤为关键。要满足 3σ 搜索窗口 ≤ 300 m（单幅成像能覆盖），修正间隔应 ≤ 5 km（约 30 s）。

### 6.3 稳态精度估计

| 误差源 | 贡献（1σ，水平） |
|---|---|
| 参考影像地理定位误差 | 3–10 m |
| 匹配算法误差（2–5 GSD） | 2–10 m |
| 姿态误差投影（1 mrad × 1 km） | 1 m |
| 时间同步误差（0.1 ms） | 0.02 m |
| 高度/DEM 误差引起的正射偏差 | 1–5 m |
| 修正间隙内推算误差（平均，修正间隔 ≤ 5 km） | 10–30 m |
| **合计 RSS** | **≈ 12–35 m** |

城区和山地基本可达 CEP ≤ 30 m；森林平缓区受修正密度影响，预计 30–50 m 量级。前提是参考库质量与可匹配性有保障。

### 6.4 主要风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 跨季节/跨时相/跨光谱匹配失败 | 修正中断 | 学习型跨模态匹配、多时相参考库、可匹配性地图规划 |
| 云层遮挡（云底低于 1 km） | 可见光/红外均失效 | TERCOM + 大气数据 + VO 降级；航路规划避云 |
| 重复纹理导致错误匹配 | 滤波发散 | χ² 门限、多假设、跨源一致性 |
| 平原/水面 | TERCOM 失效 | 以景象匹配为主，水面区段限长 |
| 参考数据过时 | 系统误差 | 发射前更新影像库，地物稳定性加权 |
| 机载算力不足 | 匹配延迟/频率不足 | 正射校正后小窗口匹配、模型量化（INT8）、参考特征离线预提取、按需触发 |
| 商用级 MEMS 温漂/振动 | 修正间隙漂移超预期 | IMU 阵列、温补、减振、提高修正密度 |
| 林区雷达高度表测冠层/地面不确定 | VO 尺度误差 | 气压−DEM 或运动恢复结构测高替代 |

## 7. 运行模式管理

| 模式 | 触发条件 | 主要信息源 |
|---|---|---|
| M0 GNSS/INS | GNSS 可用且通过欺骗检测 | GNSS + INS，同时在线标定零偏、风、相机外参 |
| M1 视觉主导 | GNSS 不可用，景象匹配有效 | INS + 景象匹配 + VO + 空速 + 高度 |
| M2 地形主导 | 景象匹配不可用，地形起伏充分 | INS + 三维地形匹配 + SITAN/TERCOM + VO + 空速 + 高度 |
| M3 推算 | 无绝对修正 | INS + VO（若可用）+ 空速/风，协方差增长告警 |
| M4 重捕获 | 协方差超过阈值后有新可匹配数据 | 大窗口景象检索 / TERCOM 批处理 |

GNSS 恢复时不直接信任：先与当前视觉/地形解做一致性检查，防止欺骗信号诱导。

## 8. 仿真与验证计划

### 8.1 阶段一：数字仿真（MATLAB/Python）

1. 轨迹生成：600 km/h、1 km 高度，含直线巡航、转弯、爬升，航程 300–600 km，穿越城区、森林山地、森林平缓区。
2. IMU 误差仿真：以商用级 MEMS 实测 Allan 方差参数为准，生成含零偏、温漂、随机游走、比例因子误差的 IMU 数据（单片与阵列两种情况）。
3. 量测仿真：按 §5.2 噪声模型生成景象匹配、TERCOM、VO、空速、高度量测，并按可匹配性地图模拟失配区段和错误匹配（离群值）。
4. ESKF 实现与 Monte-Carlo（≥ 100 次）评估：位置误差统计、NEES/NIS 一致性检验、失配区段漂移、错误匹配注入下的鲁棒性。
5. 敏感性分析：IMU 等级、修正间隔、匹配精度、延迟、时间同步误差对精度的影响。

### 8.2 阶段二：图像级半实物仿真

1. 用卫星影像 + DEM 渲染下视图像（如 AirSim/Unreal、Google Earth Studio、或自研正射渲染），引入不同季节/时相影像作为参考图与实时图。
2. 评测匹配网络的精度、成功率、错误率、耗时，并在目标嵌入式平台上测速。
3. 闭环：渲染图像 → 匹配 → ESKF → 飞控仿真。

### 8.3 阶段三：硬件在环与飞行试验

1. 低速平台（有人机/大型多旋翼/低速固定翼）挂载相同传感器载荷，在 GNSS 可用条件下采集数据，以 RTK/GNSS-INS 为真值离线回放验证。
2. 逐步提高速度至目标平台，进行“模拟拒止”（屏蔽 GNSS 输入但记录真值）飞行试验。
3. 评估指标：CEP、95% 误差、最大误差、匹配成功率、错误匹配率、各模式切换时间。
